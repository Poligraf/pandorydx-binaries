# PandoryDX Binaries

A collection of additional games, emulators, applications and game engines for the PandoryDX arcade platform.

This repository brings together a selection of precompiled software packages for compatible Pandora Box DX systems, making it easier to discover and download additional content for your device.

Browse the categories below to find available packages. Each download links directly to its corresponding ZIP archive in this repository.

## 📥 Installation

1. Browse the available packages.
2. Select the package you want and download its ZIP archive.
3. Extract the archive if required.
4. Follow any package-specific installation instructions.
5. Transfer the files to your PandoryDX installation as appropriate.

## ℹ️ Notes

- Packages are distributed as precompiled binaries.
- Some packages may require additional configuration or game data.
- Compatibility may vary depending on hardware revision and PandoryDX version.
- Always back up your existing installation before making modifications.
- Copyrighted game assets and ROMs may not be included.
